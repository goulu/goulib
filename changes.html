Changes¶

Changes¶

v3.0.4, 2026-10-27¶

  • automated Conda packaging and publishing to Anaconda.org via GitHub Actions with dedicated recipe conda/meta.yaml

  • explicit setuptools package discovery in pyproject.toml to prevent packaging extra directories

  • modernized license metadata in pyproject.toml to SPDX standard (PEP 639)

  • fix random NetworkXNoPath error in image and colors by disabling spatial tolerance on converter graphs

  • fix GeneratorExit warning in table.Table.icol()

v3.0.3, 2026-10-27¶

  • test coverage increased to >90% across the library

  • major speedup of image tests (runtime reduced from ~120s to ~5s)

  • restored documentation deployment to GitHub Pages in build workflow

  • restored sphinxdoc theme for ReadTheDocs

v3.0.2, 2026-10-26¶

  • documentation updated across modules (colors, geom, geom3d, image, math2, optim)

  • modernized datetime2 and added tests

  • additional tests and bug fixes in math2, containers, and colors

  • updated CI matrix for Python 3.14 and 3.15

v3.0.1, 2025-10-20¶

  • Linux (Mint) compatibility

v3.0.0, 2025-02-26¶

  • goulib is live again !

  • PyTest instead of nose for testing

  • github Actions for CI instead of Travis CI

  • piecewise finally passing all tests, but periodic was extracted and will run later…

  • some type hints added, but not yet complete

v2.x.y, 2020-2025¶

  • several personal updates, but never published …

v2.0.0, 2018-12-18¶

  • dropped 2.7 and six : goulib now optimal for Python 3.x

v1.6.1, 2013-12-11¶

  • table.Table.html() now returns a string (no more dependent on markup)

  • table.Table can be init’ed from an HTML file using lxml

  • added support for nose coverage tests

v1.6.0, 2013-11-25¶

  • added geom

  • dxf2img improved and added factory method to generate geom objects from dxf

  • Travis CI tests now handle local tests files. We had to use Pillow rather than PIL for this

v1.5.2, 2013-07-28¶

  • added motion and polynomial

  • created first demo IPython notebooks

  • dxf2img improved

v1.5.1, 2013-07-11¶

  • updated module description and distribution details

v1.5.0, 2013-07-11¶

  • first version with automated nose tests generated by pythoscope

  • added dxf2img to raster .dxf files (Autocad) to bitmap images

  • added math2.int_or_float()

v1.4.3 and 1.4.4, 2013-06-05¶

  • added Sphinx documentation

v1.4.2, 2013-05-17¶

  • datetime2.hhmm() replaced by more general datetime2.strftimedelta()

  • added table.Table.read_xls() to read Excel files through xlrd

v1.4.1, 2013-03-26¶

  • corrected bug in datetime2.hhmm()

  • piecewise : added shift operators

  • bug corrected in optim.tsp()

  • table :

    • added table.Table.remove_lines_where()

    • same encoding applied to all strings

    • bug corrected in table.Table.groupby()

v1.4.0, 2013-01-21¶

  • piecewise piecewise continuous functions

  • colors added color_range

  • nvd3 :

    • added nvd3.multiBarHorizontal

    • div/svg size can now be set correctly

    • more attributes supported

    • uses colors_range for nicer graphics

  • itertools2:

    • added itertools2.ilinear()

    • moved itertools2.arange() from math2

v1.3.0, 2012-12-18¶

  • nvd3.py

    • added to generate JavaScript charts using http://nvd3.org/

    • outputs strings to inline in HTML : no fancy JSON or server dependent stuff

  • markup.py now (again) prints page while generated

  • added itertools2.rand_seq(), itertools2.all_pairs(), itertools2.split()

v1.2.0, 2012-11-08¶

  • optim.py added

  • math2.py added levenshtein distances for iterables and sets

  • table.py attributes can be passed to table.html + other small changes

v1.1.4, 2012-10-19 – changes not recorded¶
