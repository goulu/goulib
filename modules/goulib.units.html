class goulib.units.Table(name, cols, cells)[source]¶

Bases: object

To create a table, use the following syntax:

t = Table('myTable', ['col1', 'col2', 'col3'],
          ['distance', V(20, 'm'), V(30, 'm'), V(40, 'm'),
           ('speed', 'm/s'), V(2, 'm/min'), V(5, 'm/s'), V(10, 'inch/s')
          ])

The row label can be a tuple of (‘label’, ‘unit’). In that case, all the values of the row will be converted to ‘unit’ (if possible) and the cells won’t display the units saving space. In the future, the label could be replaced by a dictionary having more properties like: {'label': <label>, 'comment': <comment>...}

Internally, the rows are represented as:

{'<the label>': {'col1': <value>, 'col2': <value>...},
 '<the next label>'...}
