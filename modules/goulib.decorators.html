goulib.decorators.multimethod(*types)[source]¶

Allows to overload functions for various parameter types:

@multimethod(int, int)
def foo(a, b):
    pass  # code for two ints

@multimethod(float, float)
def foo(a, b):
    pass  # code for two floats

@multimethod(str, str)
def foo(a, b):
    pass  # code for two strings
