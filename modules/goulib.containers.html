class goulib.containers.Sequence(iterf=None, itemf=None, containf=None, desc='', timeout=0)[source]¶

Bases: object

Container representing a finite or infinite numeric sequence.

Inspired by the On-Line Encyclopedia of Integer Sequences (OEIS), Sequence unifies three complementary programming concepts into a single transparent object:

  1. Generator / Iterable: for x in seq: ... iterates through the terms sequentially (potentially indefinitely).

  2. Indexable sequence: seq[i] accesses the i-th element directly, and slicing seq[start:stop:step] returns an iterator over the requested range.

  3. Set / Membership container: x in seq tests whether an integer belongs to the sequence.

Any combination of iterf, itemf, and containf can be provided to the constructor. When multiple functions are available, Sequence leverages the most efficient one for each operation:

  • If itemf is given, seq[i] runs in \(O(1)\) or without iterating from 0.

  • If containf is given, x in seq performs a fast direct membership check.

  • If iterf is given, iteration is generated sequentially via the iterator.

Computations are fully lazy: transformations (filtering, mapping, arithmetic, set combinations) build new Sequence instances without immediate evaluation. Terms are only computed when consumed.

Examples:

Defining the prime numbers (OEIS A000040) using only a primality test:

>>> from goulib.containers import Sequence
>>> from goulib import math2
>>> primes = Sequence(containf=math2.is_prime, desc="Prime numbers")
>>> 201420142013 in primes
True
>>> primes.index(7)
3

Defining the Fibonacci numbers (OEIS A000045) with optimal algorithms for generation, direct indexing, and membership:

>>> fib = Sequence(
...     iterf=math2.fibonacci_gen,
...     itemf=math2.fibonacci,
...     containf=math2.is_fibonacci,
...     desc="Fibonacci numbers"
... )
>>> fib[10]
55
>>> [fib[i] for i in range(7)]
[0, 1, 1, 2, 3, 5, 8]

Deriving new sequences using arithmetic and higher-order methods:

>>> import operator
>>> # Differences between consecutive primes / prime gaps (OEIS A001223):
>>> prime_gaps = primes.pairwise(operator.sub)

>>> # Fermat numbers 2^(2^n) + 1 (OEIS A000215) by adding scalar 1:
>>> # fermat = Sequence(itemf=lambda n: 2**(2**n)) + 1

>>> # Filter primes to Mersenne exponents (OEIS A000043):
>>> # mersenne_exp = primes.filter(math2.lucas_lehmer)

>>> # Set operations between sequences:
>>> # single_primes = primes % twin_primes  # terms in primes not in twin_primes
>>> # binary_primes = A007088 & primes      # primes written with 0 and 1 only
>>> # merged = seq1 | seq2                 # union of sorted sequences
See also:

Suites infinies et OEIS en Python (Dr. Goulu)

sort(key=None, buffer=100)[source]¶

Sort an almost-sorted (monotonically growing) infinite sequence.

Maintains a sliding buffer of size buffer using goulib.itertools2.sorted_iterable(). As long as elements are not displaced by more than buffer positions, the output sequence is guaranteed to be strictly sorted.

Example:

Ordered areas of primitive Pythagorean triangles (OEIS A024406):

>>> # A024406 = Sequence(math2.primitive_triples).apply(
... #     lambda x: x[0] * x[1] // 2
... # ).sort()
Parameters:

  • key – Optional sort key function.

  • buffer – Size of the lookahead buffer (default: 100).

Returns:

Sorted Sequence.

unique(buffer=100)[source]¶

class goulib.containers.SortedCollection(iterable=(), key=None)[source]¶

Bases: object

Sequence sorted by a key function.

SortedCollection() is much easier to work with than using bisect() directly. It supports key functions like those use in sorted(), min(), and max(). The result of the key function call is saved so that keys can be searched efficiently.

Instead of returning an insertion-point which can be hard to interpret, the five find-methods return a specific item in the sequence. They can scan for exact matches, the last item less-than-or-equal to a key, or the first item greater-than-or-equal to a key.

Once found, an item’s ordinal position can be located with the index() method. New items can be added with the insert() and insert_right() methods. Old items can be deleted with the remove() method.

The usual sequence methods are provided to support indexing, slicing, length lookup, clearing, copying, forward and reverse iteration, contains checking, item counts, item removal, and a nice looking repr.

Finding and indexing are O(log n) operations while iteration and insertion are O(n). The initial sort is O(n log n).

The key function is stored in the ‘key’ attibute for easy introspection or so that you can assign a new key function (triggering an automatic re-sort).

In short, the class was designed to handle all of the common use cases for bisect but with a simpler API and support for key functions.

>>> from pprint import pprint
>>> from operator import itemgetter

>>> s = SortedCollection(key=itemgetter(2))
>>> for record in [
...         ('roger', 'young', 30),
...         ('angela', 'jones', 28),
...         ('bill', 'smith', 22),
...         ('david', 'thomas', 32)]:
...     s.insert(record)

>>> pprint(list(s))         # show records sorted by age
[('bill', 'smith', 22),
 ('angela', 'jones', 28),
 ('roger', 'young', 30),
 ('david', 'thomas', 32)]

>>> s.find_le(29)           # find oldest person aged 29 or younger
('angela', 'jones', 28)
>>> s.find_lt(28)           # find oldest person under 28
('bill', 'smith', 22)
>>> s.find_gt(28)           # find youngest person over 28
('roger', 'young', 30)

>>> r = s.find_ge(32)       # find youngest person aged 32 or older
>>> s.index(r)              # get the index of their record
3
>>> s[3]                    # fetch the record at that index
('david', 'thomas', 32)

>>> s.key = itemgetter(0)   # now sort by first name
>>> pprint(list(s))
[('angela', 'jones', 28),
 ('bill', 'smith', 22),
 ('david', 'thomas', 32),
 ('roger', 'young', 30)]
